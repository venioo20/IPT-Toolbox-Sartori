CONFIDENTIALITÉ

Protection des données

Données conservées sur le PC

IPT Toolbox stocke localement ses réglages, les logiciels personnalisés, la clé d’activation Pro et les données du coffre de licences. Le coffre est chiffré avec la protection du compte Windows actuel. Ces données ne sont pas envoyées automatiquement à IPT Toolbox.

Paiement et demandes

Les paiements sont réalisés sur PayPal. IPT Toolbox ne reçoit pas les données bancaires, mais le responsable peut recevoir les informations de transaction nécessaires à la validation du paiement. Les demandes envoyées par courriel sont utilisées pour répondre, activer une licence, traiter un remboursement ou assurer le support.

GitHub

Les demandes et rapports publiés dans GitHub Issues sont publics. Ne publiez jamais de clé de licence, adresse client, journal non nettoyé ou autre donnée confidentielle. Les règles de confidentialité de GitHub et PayPal s’appliquent à leurs services respectifs.
