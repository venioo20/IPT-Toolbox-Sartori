DOCUMENTATION

Bien démarrer

1. Télécharger, vérifier et extraire

Téléchargez l’archive Windows depuis la dernière version GitHub. Comparez son empreinte SHA-256 avec le fichier SHA256SUMS.txt joint à la version, puis cliquez sur Extraire tout avant de lancer IPT.Toolbox.exe.

Get-FileHash .\IPT-Toolbox-Sartori-v0.4.1-win-x64.zip -Algorithm SHA256
Avertissement Windows : l’application n’est pas encore signée par un certificat commercial. Vérifiez toujours que le téléchargement provient du dépôt officiel.

2. Utiliser la simulation

Choisissez un profil ou cochez les logiciels souhaités. Le mode simulation est actif par défaut et ne lance aucune installation.

3. Installer réellement

Après vérification, cochez MODE EXÉCUTION puis cliquez sur PRÉPARER CE PC. WinGet et une connexion Internet sont nécessaires.

4. Essayer ou activer Pro

Ouvrez ACHETER / ACTIVER PRO. Vous pouvez demander un essai gratuit de 14 jours ou choisir une offre. Après validation, une clé d’activation signée vous est remise.

5. Ajouter un logiciel personnalisé

Avec Pro actif, cliquez sur AJOUTER UN LOGICIEL PERSONNALISÉ. Indiquez son nom et son identifiant WinGet exact, par exemple Piriform.CCleaner.

6. Donner votre avis

Après l’essai, utilisez le bouton DONNER MON AVIS APRÈS L’ESSAI ou le formulaire de témoignage.
